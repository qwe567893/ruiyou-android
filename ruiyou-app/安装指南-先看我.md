# 瑞友 Android App：从项目源码到两台手机视频聊天

本 ZIP 是**可继续构建的安卓应用源代码**，不是 APK。此环境无法连接你的 Supabase 账号，也没有 Android SDK；因此尚未生成 APK、也未完成两机实测。

## 1. 创建免费开始测试的后端

1. 在 https://supabase.com/dashboard 创建项目。
2. 打开项目 SQL Editor，新建查询，粘贴 `supabase/schema.sql` **全文**并执行。只需要执行这一个文件，不要导入其他旧版数据库迁移。
3. 在 Authentication > Providers > Email 启用邮箱登录，并按需要开启邮箱确认。
4. 找到 Project URL 和 Publishable key（或 legacy anon key），复制 `.env.example` 到 `.env`，替换两项 `VITE_SUPABASE_...`。不要上传 `.env`，更不能使用 `service_role`/secret key。

## 2. 在自己的 Windows/macOS 电脑上生成 APK

1. 安装 Node.js 22+，Android Studio 2025.2.1+（或最新），在 SDK Manager 安装 Android SDK。
2. 在项目目录打开终端：

```bash
npm install
npm run check
npm run android:init
npm run android:open
```

3. 等待 Android Studio Gradle Sync，然后 Build > Build Bundle(s) / APK(s) > Build APK(s)。
4. 将 `android/app/build/outputs/apk/debug/app-debug.apk` 发送到两台安卓手机安装（可能需允许安装来自未知来源的应用）。
5. 两台手机必须安装**同一份后台配置**生成的 App，但应使用**不同的账号**。

若再次修改界面，只运行 `npm run android:sync`，不要重复执行 `android:init`。

## 3. 不想安装 Android Studio：GitHub 自动编译 APK

1. 在 GitHub 新建私人仓库，上传压缩包解压后的所有源码（包括 `.github/workflows/android-debug.yml`，**不要上传 `.env`**）。
2. 进入 Settings > Secrets and variables > Actions，为仓库分别添加 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_ANON_KEY`。
3. 进入 Actions，选择 **Build Ruiyou Debug APK**，点击 Run workflow。
4. 等待运行结束，从 Artifacts 中下载 `ruiyou-debug-apk`，解压后得到 APK。

自动流程需要 GitHub Actions 提供的 Android 工具链与联网依赖下载，**此处尚未实跑验证**，如果 GitHub 编译日志报错，应按错误信息调整后重新执行。

## 4. 两台手机互相聊天视频

- A、B 两个人分别注册邮箱、验证并登录。
- A 在发现页找到 B 点击加好友；B 在消息页点击同意。
- A、B 进入聊天页，互发文字消息；消息会写入 Supabase 数据库。
- A 点击聊天页右上角的摄像头按钮，B **保持瑞友 App 在前台**看到来电后选择接听。
- 允许摄像头和麦克风权限后，可在 App 内视频聊天、静音、关摄像头、翻转镜头和挂断。

视频使用 WebRTC。公共 STUN 并不保证所有移动网络都能连通。跨 4G/5G 或严格 NAT，需要部署 TURN 中继，并把配置交给 `supabase/functions/turn-credentials` Edge Function；详见 `README.md`。
